## Kotlin in vscode

## Objetivo 
Ajudar na configuração para desevolvimento para android utilizando vscode, utilizar outros métodos de forma que não fique preso apenas no desenvolvimento uso do android studio.

## Estrutura de projeto

```text
Config-Android/
│   ├── script/          
├── linux/ 
├─── build_app.sh 🠒  script pra build de APK
├─── setup_compose.sh  🠒   Configuração de Jetpack compose
├─── tutorial.md  🠒  Configuração do linux
├── windows/ 
├─── build_app.bat 🠒  script pra build de APK
├─── setup_compose.bat  🠒 Configuração de Jetpack compose
├─── tutorial.md  🠒  Configuração do windows
```
